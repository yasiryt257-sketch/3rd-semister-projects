
# 🎮 Number System Game

A simple and fun number guessing game built using Python. The computer generates a random number between 1 and 100, and the player must guess the correct number using hints.

## 📌 Features

- 🎯 Random number generation
- 🔢 Guess a number between 1 and 100
- 💡 Hints for guesses that are too high or too low
- 🏆 Displays the number of attempts
- ⚠️ Handles invalid input
- 🐍 Beginner-friendly Python code

## 🛠️ Technologies Used

- Python 3
- Random module
- While loop
- Conditional statements
- Exception handling

## 🎮 How to Play

1. Start the game.
2. Enter a number between 1 and 100.
3. Read the hint displayed by the game.
4. Guess a higher or lower number based on the hint.
5. Continue until you guess the correct number.
6. Try to win in as few attempts as possible!
